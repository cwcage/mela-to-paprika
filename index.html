getting files in and out on iPad

  1. In Mela, open a recipe (or your whole collection) and use Share → Export to save a .melarecipe or .melarecipes file to Files.
  2. Come back here in Safari, tap the box above, and choose that file from Files.
  3. Tap Download to save the converted file to Files.
  4. Open Paprika, then import the downloaded file from Files (Paprika's import screen, or share it directly into Paprika from the Files app).

This page keeps working even if you lose signal after it first loads — the conversion runs entirely in Safari.
